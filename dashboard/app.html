Agents

Each agent proposes from one Squads vault and is bound by one policy.

Check a payment

Check a payment against the policy, exactly as the agent’s proposal is checked. Nothing is signed from this page: only the agent proposes, and only the owner-side gatekeeper casts the second vote.

The decision and every check appear here.

Ask the agent

Give the AI agent a task in plain words. The model turns it into a payment; TrustLayer's deterministic policy engine decides; the model then explains the verdict. The model can never approve, sign or override. Nothing here moves funds.

The agent's proposal, the policy verdict and the explanation appear here.

Let the agent work on its own

The agent plans over several steps: it lists vendors, reads their pages, checks its budget and asks to pay. Each payment it asks for is judged by TrustLayer. Try the poisoned vendor page: it hides instructions for AI assistants.
